## 0. Зачем

Экран отношений FEMSQ собирает узлы в хосте. Обходчик должен жить в библиотеке: хост отдаёт JSON и колбэки выборки, библиотека рисует контур или колоночный список. SQL и имена таблиц остаются у хоста.

## 1. Цель

1. Компонент `FemsqWalkTree` и чистые сборщики узлов.  
2. `v-if` на `view`: список — `FemsqTreeList`, иначе `FemsqTree`. Разметку renderer не копировать.  
3. Один числовой корень или лес по `fetchRoots` и непрозрачному `rootsToken`.  
4. `columnSets` и `level` на собранных узлах. Кнопки из JSON, эмит `action`.
