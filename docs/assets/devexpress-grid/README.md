# Эталоны DevExpress Grid (хроматика FemsqTable)

Сюда кладём **4–6** скриншотов DevExpress DataGrid / GridControl.

**Назначение:** ориентир плотности и UX-паттернов для `FemsqTable` в fequlib.  
**Не назначение:** пиксель-в-пиксель тема FEMSQ или копирование WinForms chrome.

Бриф: [../design/FemsqTable-visual-target.md](../design/FemsqTable-visual-target.md).
